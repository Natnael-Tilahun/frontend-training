# Home exercises

Build these on top of `solution/day-2` (or your own Day 2 branch), one branch and one pull request per exercise.
Use the PR template, and ask a colleague to review with the checklist in [`docs/07-senior-mindset.md`](../../docs/07-senior-mindset.md).

| #   | Exercise                                                     | Practises                                 |
| --- | ------------------------------------------------------------ | ----------------------------------------- |
| 01  | [Edit a product](01-edit-product.md)                         | reusing components, typed routes, PUT     |
| 02  | [Delete with confirmation](02-delete-product.md)             | dialogs, permissions, destructive actions |
| 03  | [Server-side search and pagination](03-server-pagination.md) | `useAsyncData`, URL state, debouncing     |
| 04  | [Unsaved-changes guard](04-unsaved-changes.md)               | route guards, form state                  |
| 05  | [Tests](05-tests.md)                                         | Vitest, testing logic not markup          |
| 06  | [Inventory dashboard](06-dashboard.md)                       | computed data, typed helpers, layout      |

Suggested order: 01 → 02 → 03, then any.
